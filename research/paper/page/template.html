Retrieval Is Not Grounding

A stage-wise audit of an evidence-backed exercise recommender — and why measuring the retriever misses every real failure.

502 studies · 1,324 exercises · 1,915 citation links 5 embedding models × 4 query formulations × 49 queries

The capstone puts a PubMed citation beside every exercise it recommends. For that citation to be trustworthy, four separate things have to go right: the study has to be graded correctly, the right studies have to be retrieved, the right study has to reach the right exercise, and the interface has to represent all of it honestly.

We measured each of those four steps separately. Three of them turned out to have ground truth already sitting in the pipeline's own data, so they cost nothing to evaluate. The headline: retrieval — the stage everyone evaluates — is not where grounding fails. Every failure we found lives in the inexpensive logic around it.

S1

The study-design grader inflates, and can only inflate

reference: MEDLINE publication types · annotation cost: none

Every study is graded into an evidence tier — meta-analysis down to other — and that tier is the largest single term in the study's retrieval weight, which then feeds the confidence score users see. The grader is a first-match keyword cascade:

if any(pattern in publication_types or pattern in title_and_abstract
       for pattern in META_PATTERNS):
    return "meta_analysis"

Notice it checks the bibliographic tags or the abstract text. So the reference condition is the system's own function, restricted to the tags. No mapping of ours sits between the system and its ground truth — it is a one-line ablation of a single design decision: should the grader read the abstract body?

It agrees with MEDLINE on 80.1% of 502 studies (κ = 0.719). Of the 100 disagreements, 19.9% grade the study stronger and 0.0% grade it weaker.

That asymmetry is structural, not empirical. Giving a first-match cascade more text can only create matches, never remove them — and the cascade is ordered strongest-tier-first. Reading more text can only promote.

The error reaches the interface: re-deriving confidence with corrected tiers moves 117 of 346 evidenced exercises, changes the displayed confidence level for 19, and changes which study is shown first for 38. The fix is one line — restrict the cascade to tags plus title, which recovers 90.8% agreement and removes more than half the inflation.

S2

How the query is written matters far more than which model embeds it

reference: corpus provenance — which boolean query fetched each study · annotation cost: none

When the corpus was built, each study recorded which boolean PubMed query pulled it in. That gives relevance labels for free — and they come from a different retrieval paradigm (boolean keyword search) than the dense vector search under test.

We varied five embedding models against four ways of writing the query. The models are chosen to settle one question cleanly: is a biomedical model better because it is biomedical, or just because it is bigger? bge-base, PubMedBERT and S-PubMedBERT-MS-MARCO are all 109.5M parameters at 768 dimensions. Size is held constant.

No model differs significantly from the shipped one (Wilcoxon p ≥ 0.062); the range across all five is 0.064 nDCG. The range across query formulations is 0.400 — about six times larger. The shipped model loses 81% of its nDCG between the raw query and the production query template.

Domain-specific pretraining did not help. At identical size, PubMedBERT was the worst arm tested. The biomedical model that performed well was the one also trained for retrieval — the discriminating factor is retrieval training, not biomedical domain.

And although no model is significantly better at retrieval, swapping the model rewrites most of the bibliography: mean Jaccard overlap with the baseline citation set is 0.32. About half of that instability is the fixed distance ceiling failing to transfer between embedding spaces; half is genuine ranking difference. Retrieval metrics were flat across a change that rewrote the citations.

S2c

So we pulled that lever, and measured what came back

intervention · winner chosen on one half of the queries, gain reported from the other

If query formulation is the dominant lever, the useful thing is to pull it rather than point at it. For a chest hypertrophy request the string being embedded was:

hypertrophy resistance training protocol | target muscles: chest |
sessions per week: 3 | split template: auto |
equipment available: barbell, dumbbell | user notes: ... |
candidate exercises: Band Bench Press, Barbell Bench Press, ...

Roughly three quarters of that is scaffolding. Sessions per week: 3 says nothing about which studies to retrieve.

Choosing the best of five rewrites and then scoring it on the same queries would be selecting on our own test set, so the 49 clusters were split deterministically in half: the winner was chosen on one half, and its gain read off the other, which played no part in the choice. The winner carries only the muscles, the goal, and what the user wrote:

chest hypertrophy resistance training | Beginner programming principles
On held-out queries: 0.215 against 0.091 — a 137% gain, p = 0.0088, better on 12 of the 13 queries that moved. It improves every embedding model tested, and the share of requests yielding any citation is unchanged at 86%.

Two side questions fell out. Equipment tokens are neutral. Candidate exercise names are actively harmful — catalog product names like Band Two Legs Calf Raise - (Band Under Both Legs) V. 2 are dense with variant and equipment words that abstracts never use.

S2b

The one hard filter is calibrated to a single embedding space

reference: off-topic probe set · annotation cost: none

The engine drops any retrieved passage beyond a cosine distance of 0.50, and the code documents this as calibrated against off-topic probes — "yoga, nutrition, swimming". Those probes are not in the repository, so the claim cannot be reproduced. We supply a probe set that can be.

The ceiling turns out to be a property of the embedding space, not of the corpus. Under the shipped model it admits 4.3% of the corpus. Under three of the four alternatives it admits 94.6–100% and rejects none of the off-topic probes; under the fourth it admits 1.5%. The best separating ceiling ranges from 0.200 to 0.525.

Even for the shipped model the documented range overstates the filter: in-domain queries reach 0.821, so some legitimate questions are silenced entirely — and four of our five adjacent probes, including the yoga, nutrition and swimming cases the comment names, pass straight through.

S3

The corpus holds the science; the name-matching step loses it

reference: human and model adjudication · annotation cost: 25 items

Independently of retrieval, each exercise is linked to studies whose text contains one of its name aliases. The project documents this as intentional — movement-level rather than per-variant attribution. We measured what that decision costs.

Only 346 of 1,324 exercises (26.1%) carry any citation, and only 145 of 502 studies (28.9%) ever attach to one. At request time it falls to 18.9% for a hypertrophy request. Coverage ranges from 0% to 64% by muscle — and does not follow supply.

The pipeline ran dedicated queries to fill the forearm evidence gap and fetched 20 studies on grip and forearm training. Not one of the 37 forearm exercises cites any of them. Same for traps, 0 of 17. Same for hip abductors, 0 of 5, from 30 fetched studies.

The mechanism explains it. Of 1,970 distinct catalog aliases, only 57 ever match a study — and 49 of those 57 are exactly two words long. Matched aliases average 2.21 words; the catalog averages 3.59. Attribution only fires for movements that happen to have a short, generic name.

The consequences compound: one study is cited for up to 47 different exercises, and the 346 evidenced exercises share only 50 distinct citation lists — the largest group being 36 exercises with byte-identical citations.

Judging sampled citations at three increasing levels of claim specificity shows support collapsing as the claim sharpens. One failure category we did not anticipate: the matched term naming a clinical assessment test rather than an exercise. The alias "leg raise" matched a randomised trial of deep-oscillation massage therapy for hamstring flexibility — there, a leg raise is a flexibility test, not something anyone trained.

S4

What the interface promises, checked against what it does

reference: the system's own published methodology page · annotation cost: none

The app publishes a methodology page with its formulas and explicit claims. Auditing a system against its own public specification is cheap, and it is the last link in the chain — it is what a user actually reads.

The most consequential guardrail holds: the heuristic confidence path is capped below the "high" threshold, and no zero-evidence exercise is ever labelled high. But the label beneath it does a great deal of work — "moderate" is applied to 1,006 exercises of which only 5.9% have any linked study.

Why this is a paper

A protocol others can reuse

Literature-RAG pipelines already produce their own ground truth and then discard it. The bibliographic index supplies study-design labels; the boolean queries that assembled the corpus supply relevance labels. Three of the four stages need no manual labelling at all — any team building a PubMed-backed system can run this in an afternoon.

A finding that generalises

The mechanisms are architectural, not local. First-match keyword cascades over widening text inflate monotonically. Absolute distance thresholds do not transfer across embedding spaces. String-match attribution is biased toward entities with short generic names. Blending heuristic priors with evidence yields a score that cannot express the absence of evidence.

What we changed, and what we left alone

Four findings were acted on — the query builder was scoped, the dormant citation-containment check was wired into every generation, the API's evidence appendix was aligned with the Markdown export, and two stale published counts were corrected. All 73 engine tests pass unchanged.

One was left alone deliberately. Restricting the study-design grader to publication types and titles would remove more than half the tier inflation — but tier scores are baked into the corpus, the catalog and the vector store, so making it take effect means rebuilding all three, which shifts rankings the existing quality tests assert on. S1 already measures what that change is worth, so the recommendation is reported rather than risked. Knowing which findings are worth acting on is part of the result.

What the system gets right

This is not a list of bugs — every mechanism measured is a documented design decision, and the paper reports what those decisions cost rather than treating them as defects. Three things were verified as sound: the ranking surfaces evidenced exercises 2.8× more often than the rest of the catalog; retrieval returns an honestly empty result rather than padding with weak matches; and ranking ties are surfaced rather than concealed.
